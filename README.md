Prototipo de lista doblemente enlazada circular con centinela (con GUI)

Archivos incluidos:
- linked_list.py : implementación y demostración paso a paso (versión consola).
- app_gui.py : interfaz gráfica con visualización de nodos, operaciones y log.
- documento_entrega.md : documento de entrega con descripción, justificación y
  referencias (formato APA).

Cómo ejecutar la interfaz gráfica (recomendado):
1. Abrir una terminal en la carpeta del proyecto.
2. Ejecutar: python app_gui.py
3. Usar los campos de entrada y los botones para añadir, buscar y eliminar
   iniciativas. Capturar las pantallas del lienzo y del panel de logs como
   evidencias.

Ejecución por consola (opcional):
1. Ejecutar: python linked_list.py
2. El programa imprimirá un demo paso a paso; tomar capturas de la salida.

Sugerencias de evidencia a capturar:
- Pantalla del lienzo mostrando varios nodos (después de varias inserciones).
- Resultado de una búsqueda con el nodo resaltado.
- Log que muestra la eliminación de un nodo y el estado posterior.
- Salida de la demostración por pasos (si se usa la versión consola).

Notas adicionales:
